# BaylonCredit IA

Plataforma web para **Cervecería Baylón**: sistema de gestión de créditos, ventas, fiados, pagos y evaluación crediticia.

## Fase 1 — Base del frontend

Rama: `feature/frontend-base`

Stack:

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router

## Comandos

```bash
npm install
npm run dev
npm run build
npm run lint
```
